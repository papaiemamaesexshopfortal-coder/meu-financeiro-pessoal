Instalar Meu Financeiro

Instalar em outros dispositivos
  • iPhone e iPad: Safari → Compartilhar → Adicionar à Tela de Início.
  • Windows e Linux: Chrome ou Edge → menu → Instalar aplicativo.
  • macOS: Safari → Arquivo → Adicionar ao Dock, ou menu Instalar no Chrome/Edge.
  • Android: Chrome → menu → Instalar aplicativo, ou use o APK disponibilizado para testes.

Entre com a mesma conta para sincronizar seus dados. Instale enquanto estiver conectado à internet.
